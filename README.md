# 📊 Adidas Sales Performance Dashboard

## 📝 Project Overview
This project features an interactive dashboard designed to analyze Adidas sales performance across multiple regions and channels. The objective is to transform raw sales data into actionable executive insights, highlighting key drivers of revenue and product performance.

## 🎯 Executive Insights
Based on the data analysis, key takeaways include:
* **Total Units Sold:** 2,478,861
* **Leading Product:** Stan Smith (246 units)
* **Top Regional Market:** Iraq (1,077 units) & Egypt (1,044 units)
* **Primary Sales Channel:** Online (1,601 units)
* **Discount Activity:** Highest in Iraq (371 records)

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data cleaning, transformation, and modeling.
* **Pivot Tables & Charts:** For dynamic data summarization.
* **Slicers & Timelines:** To create an interactive and user-friendly interface.
